#### Featured project — [Movie & TV Social Platform (backend)](https://github.com/VimingOfficial/movie-social-platform-backend)

A Django REST Framework backend for a social platform built around movies and TV shows: one catalogue for both media types, watchlists and progress tracking, reviews and ratings, custom lists, a social graph with a ranked feed, notifications, discovery, and an explainable recommendation engine built from a user's own watch history.

- **11 Django applications**, **124 REST endpoints** / 153 operations documented with OpenAPI 3
- **1,575 automated tests**, all passing — the suite is hermetic and needs no network
- JWT authentication, object-level visibility rules, per-domain rate limiting
- TMDB integration isolated behind a caching client; append-only activity stream; the feed is a read layer over it
- Deterministic, explainable scoring and ranking — no ML black boxes
- The repository documents its own [feature matrix](https://github.com/VimingOfficial/movie-social-platform-backend#feature-completion-matrix), phase plan and roadmap, with a security policy and contribution guide
- The backend is my work; the frontend is a separate codebase built by a collaborator
