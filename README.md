#### Current work — Movie & TV Social Platform (backend)

A REST backend for a social platform around movies and TV shows: one catalogue for both media types, watchlists and progress tracking, reviews and ratings, custom lists, a social feed, notifications, discovery and statistics.

- 11 Django applications, 124 REST endpoints across 11 API domains
- JWT authentication, object-level visibility rules, per-domain throttling
- TMDB integration isolated behind a caching client; append-only activity stream; feed as a read layer
- 1,575 automated tests (hermetic — no network access in the suite)
- 10 architecture decision records and per-domain architecture documentation

The backend is my work; the web frontend is built by a collaborator. The repository is being prepared for public release and will be linked here when it is published.
